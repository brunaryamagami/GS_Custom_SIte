# GS Custom

Primeira base do site institucional/catalogo para a marca GS Custom, focada em carrinhos de colecao.

## O que esta pronto

- estrutura inicial da Home
- pagina inicial de catalogo
- modelo de pagina de produto
- categorias principais do catalogo
- cards de exemplo para produtos
- secoes de personalizados, galeria, FAQ e contato
- documentos de planejamento em `planning/`

## Como abrir

Basta abrir [index.html](./index.html) no navegador.
